任何 ML 项目都走这条路

Universal machine-learning workflow

1收集数据→2清洗/选特征→3训练/测试拆分→4选模型并训练→5评估与改进
训练集 Training约 75–80%：让模型学习
测试集 Test约 20–25%：最后检查

为什么随机拆分？如果前 80 行刚好全是同一类别，模型会学偏。Cross-validation 再把训练集轮流分成训练/验证，减少一次拆分带来的偶然性。

Overfitting 过拟合训练数据表现很好，新数据却很差；像“背熟练习题但不会变式”。原卷把“Cross-validation 用于防止 underfitting”判为 False：这里要记 overfitting，不是 underfitting。

Supervised Learning 监督学习 · 有标签 y

Classification · 分类 输出离散类别
Logistic Regression重点预测类别或概率；名字有 Regression，但通常用于分类。Naïve Bayes认名基于概率进行分类，例如垃圾邮件判断。SVM认名寻找区分类别的最佳边界。
Regression · 回归 输出连续数字
Linear Regression重点找 best-fit line，预测房价、销量、温度等数值。
Both · 两者都能做 看题目输出决定
Decision Tree认名分类时输出类别；回归时输出数值。Random Forest认名分类用多棵树投票；回归用多棵树取平均。KNN认名分类看邻居投票；回归看邻居数值的平均。

Unsupervised Learning 无监督学习 · 没有标签 y

Clustering · 聚类 Group similar data
K-means重点排他聚类：每个点分给最近的 centroid。C-means / Fuzzy C-means认名模糊聚类：一个点可按不同程度属于多个簇。
Association Rules · 关联规则 Find items occurring together
Apriori重点找 frequent itemsets，再计算 support、confidence、lift。
课程中的其他任务 先记用途，当前材料未配指定算法
Anomaly Detection发现异常数据，例如异常交易。Recommendation推荐相关内容，例如推荐电影。Dimensionality Reduction减少特征数量，同时尽量保留重要信息。

Reinforcement Learning 强化学习 · 行动后收到奖励

它不分“分类/回归”；两种算法都在学习哪一个 action 更值得做，区别是更新策略。

Off-policy · 脱离当前策略学习
Q-learning认名用下一步“最佳动作”的价值更新 Q 值，学习目标策略。
On-policy · 跟随当前策略学习
SARSA认名按实际采取的下一步动作更新：State–Action–Reward–State–Action。
一句话分层有标签 → 先看分类/回归；无标签 → 看聚类/关联等任务；有奖励 → 看策略如何学习。
考试最实用的判断题目要求类别 → Classification；要求连续数字 → Regression；没有答案而要找群组 → Clustering；找经常同时出现的项目 → Association Rules；行动后根据 reward 改进 → Reinforcement Learning。

混淆矩阵与评价指标

Confusion matrix metrics

Pred +Pred −Actual +TPFNActual −FPTN

Accuracy = (TP + TN) / All全部预测中答对多少

Precision = TP / (TP + FP)预测为正的里面有多准

Recall = TP / (TP + FN)真正正类中找回多少

F1 = 2 × P × R / (P + R)同时兼顾 Precision 与 Recall

为什么不能只看 Accuracy？

100 人中 90 人健康、10 人患病；模型把所有人都预测成健康，Accuracy 仍有 90%，但 10 名患者一个都没找出来，Recall = 0。

记分母Precision 看“预测正”；Recall 看“实际正”。类别极不平衡时，还要看 Precision、Recall、F1 和 confusion matrix。

03

层次聚类：先看第一次合并

Hierarchical clustering & dendrogram

ABCD

Agglomerative 凝聚式
每点各自一组，最近的先合并。Bottom-up。

Divisive 分裂式
全部先在一组，再逐步拆开。Top-down。

Single取最小距离Complete取最大距离Average取平均距离Centroid比较两个中心
一步小题d(A,B)=2　d(A,C)=4　d(B,C)=7最先合并 A、B，因为 2 最小。合并后到 C：Single = 4；Complete = 7；Average = 5.5。
最像考试的问法给很小的距离矩阵，问“谁先合并”或“Single/Complete 更新后的距离”。完整大型 dendrogram 只需看懂流程。

Support(X∪Y)同时含 X、Y 的交易数 / 总交易数一起出现得多不多？Confidence(X→Y)同时含 X、Y / 含 X 的交易数买 X 后也买 Y 的比例Lift(X→Y)Confidence(X→Y) / Support(Y)>1 正相关；=1 独立；<1 负相关

一步小题：直接从上面的数量卡取数，不靠脑补。

support(B∪M)=2/5=0.40
confidence(B→M)=2/3≈0.67
lift=(2/3)/(2/5)≈1.67

Lift > 1，说明 Bread 与 Milk 是正关联。
