## 第 1 章

**1.** 训练是备考：用大量数据把模型做出来。推理是考试：用学到的东西对新数据做预测。（第 32 页）

训练的目标是学会一项任务，数据是整理过的大数据，常要 GPU 或 TPU。推理的目标是在新数据上给出预测或决定，数据是模型没见过的实时数据，可以跑在服务器上，也可以跑在更省电的小设备上。（第 33 页）

**2.** （第 9 页）

1. The Early Vision，1950s–1970s：Turing Test，1956 Dartmouth Conference。
2. The Rise of Expert Systems，1980s：模仿人类专家的程序。
3. The Machine Learning Era，1990s–2010s：从规则系统转到数据驱动学习。
4. The Deep Learning Revolution，2012s–2025s：受人脑启发的神经网络。
5. The Future of AI，2026–Present：Generative AI，Ethical AI，Artificial General Intelligence。

**3.** （第 12 页）

- Reactive：Narrow AI。例子是垃圾邮件过滤、聊天机器人，或 Spotify / Netflix 推荐。
- Limited Memory：Narrow AI。例子是 ChatGPT 这类生成式工具、自动驾驶，或语音助手。
- Theory of Mind：Strong AI。定义是理解其他智能体的需求。
- Self-Aware：Strong AI。定义是发展到有类人智能和自我意识。

Narrow AI 今天就存在。Strong AI 在这页上被写成概念或理论。

**4.** （第 13 页）三条主干是 Machine Learning，Decision Making，Natural Computing。

监督学习的例子可以写神经网络、回归或决策树。无监督学习的例子可以写聚类或降维。强化学习在这页是单独一支，讲义没有再拆例子；写「试错、有奖励和惩罚」来自第 34 页，也算讲义内。

**5.** 聊天机器人回一句文本就结束。AI agent 持续循环 reasoning，acting，evaluating。（第 15 页）

**6.** 云是数据集中在数据中心。边是在设备或数据源附近处理。云边混合可以在云上训练、在边上推理。（第 17–19 页）

Federated learning 在多台边缘设备上训练，不共享原始数据。

**7.** （第 61 页）

- Input Normalization：把输入标准化，例如 z-score 或 min-max。
- Batch Normalization：在一个 mini-batch 里把激活归一化。
- Gradient Clipping：限制梯度的范数，防止梯度爆炸。

## 第 2 章

**9.** （第 15 页）

- Neuron：接收输入，带阈值和激活。
- Connection：在神经元之间传信息。
- Weights and Biases：决定连接有多强、偏移多少。
- Propagation function：在层之间加工并传递。
- Activation function：加在神经元输出上。
- Learning rule：改权重和偏置，提高准确度。

**10.** （第 17–18 页）

```text
z = w · x + b
a = f(z)
```

`w` 是权重，`x` 是上一层输入，`b` 是偏置，`f` 是激活函数。

**11.** （第 20–21 页）前向算出输出；算误差；梯度往回传；更新权重。

```text
w_new = w_old - η ∂L/∂w
```

梯度还告诉你往哪个方向改。

**12.** （第 28、31、32、35 页）

| 函数 | 输出范围 | 一个优点 | 一个缺点 |
| --- | --- | --- | --- |
| Sigmoid | 表上写 [0, 1]；公式页是 (0, 1) | 适合二分类，输出可看成概率 | 两端饱和，梯度接近 0；输出不是零中心 |
| Tanh | [-1, 1] | 零中心，训练比 Sigmoid 快 | 饱和时仍有梯度消失 |
| ReLU | [0, ∞) | 正输入不饱和，收敛快 | dying ReLU，负半轴可能再也不更新 |
| Softmax | (0, 1) 且各类和为 1 | 多分类输出成概率 | 不适合多标签，各类被逼成互斥 |

**13.** 没有非线性时，很多层的加权和仍能合成一个线性变换，整个深网等价于一层线性模型。（第 27 页，也对应第 3 章第 30 页 c 问）

Sigmoid 在很大的正输入和很大的负输入处饱和，导数接近 0。反向传播要连乘这个导数，深层几乎收不到有用的梯度，收敛变慢。（第 22、30、35 页）

**14.** （第 41 页）

- 每日气温序列：RNN
- 压缩再重建以找异常：Autoencoder
- 生成逼真图片：GAN
- 长文本且要并行：Transformer

**15.** （第 47 页）

```text
ŷ = 0×1 + 0 = 0
L = (0 - 2.5)^2 = 6.25
```

**19.** （第 23–26 页）负数不能直接当概率，指数把分数变成正数。Apple 最高，86.7%。四类经 Softmax 后加起来是 100%。其余是西瓜 3.3%、葡萄 4.3%、香蕉 5.5%。

**20.**

```text
e^2 ≈ 7.389
e^0 = 1
和 ≈ 9.389
P(第一类) ≈ 0.787
P(第二类) ≈ 0.1065
P(第三类) ≈ 0.1065
```

保留三位小数时，0.1065 会进到 0.107。两个 0.107 再加 0.787 会变成 1.001，这是舍入，不是另一套 Softmax。三类之和在未舍入时应为 1。

**21.** （第 27–30 页，与课堂练习答案一致）

a) 特征的数值范围可能差很多。某个特征特别大时，会主导加权和，即使它的权重不大。缩放到相近范围，训练更稳，也更快收敛。激活函数单独解决不了这件事。

b) 激活函数引入非线性，隐藏神经元才能表示更复杂的关系。

c) 多层加权和仍能合成一个线性变换，整个深网还是一个线性模型，加层也学不会非线性模式。

d) ANN 可以用多层和激活函数学习颜色、大小、形状、重量之间的非线性关系。简单线性分类器只能用一条线性边界分开数据。

**24.** （第 37–38 页）

```text
L = -log(0.78) = 0.248
误差 = 0.78 - 1 = -0.22
```

**25.** （第 40 页）规则要人事先写好。ANN 用反向传播和梯度下降，自己学出很多加权组合，测量有噪声或不完整时仍能分类。

**28.** （第 54–56 页）

- 隐藏层：ANN 可以很多层；RBF 严格一层。
- 参数：ANN 是权重和偏置；RBF 隐藏层是中心和宽度 σ。
- 训练：ANN 用反向传播；RBF 是选中心，再训练输出权重。

## 第 4 章

**29.** （第 21–22 页）序列的例子是语言或按时间排列的数据，顺序改变意义就变。非序列的例子是欺诈检测那张表：每一行一笔申请，列是特征，行的先后没有时间含义。

**30.** （第 24 页）总数 9000，`P(coffee | cup of) = 5000/9000`。预测 coffee。

**31.** （第 27–30 页）bigram 是 `1000^2 = 1,000,000`。trigram 是 `1000^3 = 1,000,000,000`。

三个限制：数据稀疏，intelligent 和 brilliant 会被当成不同模式；窗口固定，trigram 够不着句首的 fruit；内存，词表 100,000 时 trigram 数量是 `100000^3`。

**32.** （第 47、50–51 页）

```text
h_t = f(W_xh x_t + W_hh h_{t-1} + b_h)
y_t = g(W_hy h_t + b_y)
```

每个时间步共用同一套权重，所以句子变长不必加宽输入层。BPTT 把时间展开成一层一层，但这些层的权重矩阵是同一套，普通深网每一层可以有自己的权重。

**33.** （第 56–59 页）消失：激活导数小于 1，沿时间连乘，梯度指数变小。讲义说这是 RNN 结构的后果，不是调参能去掉的，要换结构。爆炸：连乘的数大于 1，更新过大；实践里可以用梯度裁剪。`h1 = 1.0` 到 `h10 = 0.06` 说明开头那个词的特征在固定长度的隐藏状态里被冲淡。

**34.** （第 62 页）One-to-Many：图像描述。Many-to-One：一句话的情感正负。Many-to-Many：机器翻译，或视频逐帧。

**35.** （第 66–79 页）细胞状态是长期记忆传送带。隐藏状态是短期记忆，也是交给下一步的输出。

遗忘门问该忘掉什么，输入门问该记住什么，输出门问该露出什么。

```text
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C~_t
h_t = o_t ⊙ tanh(C_t)
```

Vancouver 0.1 是遗忘门在丢掉过时的城市。Paris 0.95 是输入门在强写入新事实。

**36.** （第 84、89 页）合并成一个隐藏状态；遗忘门和输入门合成更新门，用 `z_t` 和 `1-z_t` 互补；用重置门代替单独的输出门。

参数大约少 25%，因为 4 套权重变成 3 套。矩阵乘法更少，通常更快，适合小数据或算力紧的场合。极长、极细的时间依赖上，LSTM 单独的细胞状态可能更强。

**37.** （第 100–105 页）

1. 每个词变成向量。
2. 每个词有 Query、Key、Value。it 的 Query 在找指代对象。
3. it 和每个词的 Key 比较，animal 的分数 0.60 最高，tired 是 0.20。
4. Softmax：animal 60%，tired 20%，because 9%，street 5%，其余 6%。
5. 用这些权重去混合对应的 Value。
6. it 不再只是代词，表示里带上了 animal 和 tired，也就是那只疲倦的动物。

**38.** （第 99、106–107 页）点积得到对齐程度，除以 `sqrt(d_k)` 是为了梯度更稳，Softmax 把分数变成和为 1 的注意力权重。一头是一套独立的注意力，专门看一种关系，例如指代或主谓一致。

**39.** （第 108–109、116 页）Transformer 一次看全部位置，本身没有从左到右的顺序，所以要用 positional encoding 把词序加回去。

一个 block 的两个子层是 Multi-Head Self-Attention，和 Position-wise Feed-Forward（两层线性，中间 GELU 或 ReLU）。

并行训练：只有 Transformer 是 Yes。现代大模型的基础：Transformer。

**44.** 先用当前权重做前向预测，用损失函数看错了多少，再把误差梯度传回去，按 `w_new = w_old - η ∂L/∂w` 更新每一个权重。这就是学习规则。投影没有要求写出 Adam 或其他优化器。

**45.**

2. 有时间或先后关系。股价在不同时刻各记一个值。

深度学习结构：RNN、Transformer、LSTM。传统统计：自回归模型，用于时间序列分析和预测。

**46.** 两件事是 token 之间的注意力，以及每个 token 的位置编码。顺序是 INPUT WORD，再 EMBEDDING 加上 POSITIONAL ENCODING，再 SELF ATTENTION，得到 CONTEXTUAL EMBEDDING。

处理 mouse 时可以直接看 cat 和 chased，不必穿过多个隐藏状态。距离变成 1 步。
