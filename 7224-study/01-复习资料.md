人判断学生，机器用同样的结构：

| 课程 | 机器学习 |
| --- | --- |
| 作业、期中、项目、考试的分数 | 输入特征的取值 |
| 各项占比 | 权重 |
| 加分 | 偏置 bias |
| 分数段对应等级 | 激活 |
| 教师的评分政策 | 学习算法 / 模型设计 |
| 最终等级 | 输出 |

讲义例子：占比 20%、20%、30%、30%。分数 80、70、90、75。

```text
79.5 = 80×0.2 + 70×0.2 + 90×0.3 + 75×0.3
     = 16 + 14 + 27 + 22.5
加分 bias = 3，最终 82.5
等级：>80 且 <=85 为 A，所以是 A
```

对应的写法是线性形式再套一个激活：先 `y = w·x + b`，再按区间映射等级。

Week 2 讨论用的是另一张表，权重是 Assignment 1 为 5、Assignment 2 为 5、Midterm 为 20、Project 为 30、Exam 为 40。旁边的 rating 是 95%、85%、100%、95%，考试那格是问号，所以总分算不完。已知四项贡献 57.5，考试贡献 `40 × 考试分数的百分数`。对照表和下载 PDF 相同：分数是特征值，占比是权重，最终等级是输出。

权重是某项输入对输出的贡献强度，偏置是另一项参数。自适应学习是：把网络放到数据上，按新数据改权重和偏置，反应跟着变。

9 月 18 日课堂把第 13 页收成一个问题：How to learn the values of all the weights which generate a good prediction? 投影上没有给答案。按后面几页，答案就是学习规则：前向算出预测，用损失看错多少，再用梯度把每个权重往更准的方向改。这题不要另背一套优化器名字。

第 15 页要能默写的部件：

- Neuron：接收输入，有阈值和激活函数。
- Connection：神经元之间传信息。
- Weights and Biases：连接的强度和偏移。
- Propagation function：在层与层之间加工、传递。
- Activation function：加在神经元输出上的函数。
- Learning rule：随时间改权重和偏置，用来提高准确度。

网络从数据里找规律，不靠事先写死的规则。

每个神经元里其实是两步：

```text
z = w · x + b
a = f(z)
```

`w` 是权重，`x` 是上一层来的输入，`b` 是偏置，用来移动激活门槛。`f` 是激活函数。

预测出来以后，用损失函数 `L` 看错了多少。反向传播靠链式法则，算损失对每一个权重的偏导，再把权重往减小损失的方向改。

训练四步：

1. 前向算出输出。
2. 算误差。
3. 误差梯度往回传。
4. 更新权重：`w_new = w_old - η ∂L/∂w`。

往回拆一个隐藏层权重时，讲义点了三项：上一层传下来的误差梯度；激活函数的导数（Sigmoid 这一项最大约 0.25，所以梯度会变小）；线性部分对权重的导数，就是输入 `x` 本身。

中心句：预测错了，就改权重，让下一次更接近。梯度同时告诉你改多少、往哪边改。

三阶段（第 25 页）：送入数据，按当前参数出结果，反复改权重和偏置。

作用有两个：

1. 非线性。没有它，叠多少层都还是一个线性模型。
2. 控制这个神经元开还是关。输出可以是非零（激活）或零（不激活）。

隐藏层通常用同一种激活；输出层按任务另选。

Sigmoid（第 28–29 页）：

```text
σ(z) = 1 / (1 + e^{-z})
输出落在 (0, 1)
导数 σ'(z) = σ(z) (1 - σ(z))
```

大的正输入接近 1，大的负输入接近 0。光滑、可导，所以能做梯度学习。二分类例子：垃圾邮件、及格、欺诈、患病。通常用 0.5 当阈值。讲义给的读数：`z = -3` 时约 4.7%，`z = 0` 时 50%，`z = 3` 时约 95.3%。

第 30 页的图：两端饱和，饱和区导数接近 0。

第 31–32 页的对照表，期中优先背这四行：

| 函数 | 用在 | 公式与范围 | 优点 | 缺点 |
| --- | --- | --- | --- | --- |
| Sigmoid | 隐藏或输出 | `1/(1+e^{-x})`，表上写 [0, 1]；公式页写的是开区间 (0, 1) | 光滑，适合二分类，历史上常用 | 饱和导致梯度消失；输出恒为正、不是零中心；`exp` 贵 |
| Tanh | 隐藏 | `(e^x - e^{-x}) / (e^x + e^{-x})`，[-1, 1] | 零中心，比 Sigmoid 好训练 | 饱和时仍有梯度消失 |
| ReLU | 隐藏 | `max(0, x)`，[0, ∞) | 正半轴不饱和；只激活一部分神经元，算得快；比 Sigmoid / Tanh 收敛快 | 输出不是零中心；dying ReLU：负半轴卡住后不再更新 |
| Leaky ReLU | 隐藏 | `max(0.01x, x)`，负半轴也可写成 `max(ax, x)` | 保留 ReLU 的好处，负半轴仍有小梯度 | 负半轴斜率 `a` 要调。讲义把这一种也叫做 Parametric ReLU |
| ELU | 隐藏 | `x`（x>0），`a(e^x-1)`（x<0），`a` 常取 1 | ReLU 的好处，输出更接近零中心，负向会饱和所以更抗噪 | 有指数，更贵 |
| Softmax | 输出 | `P(y_i) = e^{z_i} / Σ e^{z_j}` | 多分类，输出变成和为 1 的概率 | 不适合多标签，因为它强迫各类互斥、只突出一类 |

第 33–34 页还有 GELU、Swish、SELU 等曲线。知道「隐藏层有很多 ReLU 变体，输出层多分类用 Softmax」即可，不必背每条公式。

对性能的三点（第 35 页）：

1. 收敛：ReLU 避开梯度消失，Sigmoid 和 Tanh 在深层里变慢。
2. 梯度：ReLU 让深层还能学；Sigmoid 梯度小。
3. 任务：Softmax 负责多分类；ReLU、Leaky ReLU 用在普通层。

第 36 页课堂练习：除 Sigmoid 外选一个激活函数，写优缺点。ReLU 作业已经写过。对照表里 Tanh、Leaky ReLU、Softmax 同样能答。

ANN 是互相连接的节点，从经验里改连接，不用把规则一条条写死。结构是输入层、一层或多层隐藏层、输出层。学习就是用反向传播改权重，让输出靠近目标。

| --- | --- | --- | --- | --- |

| Transformer | 自注意力、位置编码、前馈 | NLP、视觉、多模态 | 长距离依赖，可并行 | 费算力，要大量数据 |
| GAN | 生成器和判别器对抗 | 生成图像、超分 | 能生成逼真数据 | 难训练，模式崩溃，对超参数敏感 |

四个点没有严格共线：`x = 1, 2, 3, 4`，`y = 2.5, 3.7, 5.1, 7.8`。

没有隐藏层：`ŷ = w x + b`。优化器 SGD，学习率 `0.01`，损失是平方误差 `L = (ŷ - y)^2`，讲义训练到 500 个 epoch。初始 `w = 0`，`b = 0`。

梯度用的是这个损失，不是前面再乘 `1/2` 的那种写法：

```text
∂L/∂w = 2 (ŷ - y) x
∂L/∂b = 2 (ŷ - y)
w ← w - 0.01 ∂L/∂w
b ← b - 0.01 ∂L/∂b
```

第一个点 `(1, 2.5)`：

```text
ŷ = 0
L = (0 - 2.5)^2 = 6.25
∂L/∂w = 2(0 - 2.5)(1) = -5
∂L/∂b = -5
w = 0 - 0.01×(-5) = 0.05
b = 0.05
```

第二个点 `(2, 3.7)`：

```text
ŷ = 0.05×2 + 0.05 = 0.15
L = (0.15 - 3.7)^2 = 12.6025
∂L/∂w = -14.2 ，∂L/∂b = -7.1
w = 0.192 ，b = 0.121
```

第三个点 `(3, 5.1)`：预测 0.697，损失 19.3864，梯度 -26.418 和 -8.806，更新后 `w = 0.4562`，`b = 0.2091`。

第四个点 `(4, 7.8)`：预测 2.0338，损失 33.2493，梯度 -46.1298 和 -11.5324。

一个 epoch 结束：`w` 从 0 到 0.9175，`b` 从 0 到 0.3244。

继续训练后的讲义结果：

| | 权重 | 偏置 | 直线 |
| --- | --- | --- | --- |
| 100 epochs | 1.5698 | 0.9210 | `ŷ ≈ 1.5698 x + 0.9210` |
| 500 epochs | 约 1.6841 | 约 0.5849 | `ŷ ≈ 1.6841 x + 0.5849` |
| 最小二乘直线 | 1.7300 | 0.4500 | 这四个点的最佳直线 |

没有隐藏层时，网络做的就是线性回归。500 轮已经靠近最小二乘，还没有完全重合。损失曲线随训练下降。

若一个特征的数值远大于其他特征，即使它的权重不大，也会主导 `z = Σ w_i x_i + b`。激活函数只能限制信号继续变大，不能从根上解决尺度不一致。主办法是在送进网络之前做归一化。

课堂讨论给了归一化之前的数。权重仍是颜色 0.7、大小 0.6、甜度 0.3、水分 0.3，但水分的原始值是 400，不是 4：

```text
z = 4×0.7 + 3×0.6 + 3×0.3 + 400×0.3
  = 2.8 + 1.8 + 0.9 + 120
  = 125.5
```

水分单独贡献 120，其余三项加起来只有 5.5。这时再套 Sigmoid，`z = 125.5` 的输出已经饱和成 1，大数被压住了，但网络几乎只在看水分。激活解决不了「谁在主导」。

把水分除以 100 之后，四个特征变成颜色 4、大小 3、甜度 3、水分 4：

```text
z = 4×0.7 + 3×0.6 + 3×0.3 + 4×0.3 = 2.8 + 1.8 + 0.9 + 1.2 = 6.7
a = sigmoid(6.7) = 0.998
```

没有单一特征独大。完整步骤在 `04-Discussion考点.md`。

| --- | --- | --- | --- | --- |

| Grapes | 0.7 | 0.8 | 0.2 | 0.85 |
| Banana | 1.0 | 0.9 | 0.6 | 0.60 |

标签是 one-hot。顺序按讲义表头 Banana、Grapes、Apple、Watermelon 从左到右读会绕，正文后来的输出顺序是 Watermelon、Apple、Grapes、Banana。记输出顺序以第 36 页为准：`y1` 西瓜，`y2` 苹果，`y3` 葡萄，`y4` 香蕉。西瓜的目标是第一类为 1、其余为 0。

只演示一个隐藏神经元 H1。权重：颜色 0.8，甜度 0.6，大小 0.5，水分 0.9，偏置 `-1.0`。一颗果：颜色 0.8，甜度 0.7，大小 0.9，水分 0.95。

```text
z = 0.8×0.8 + 0.6×0.7 + 0.5×0.9 + 0.9×0.95 - 1.0
  = 0.64 + 0.42 + 0.45 + 0.855 - 1.0
  = 1.365
h1 = 1 / (1 + e^{-1.365}) ≈ 0.796
```

讲义说它被较强激活，是因为这些特征和西瓜接近。其余隐藏神经元重复同样两步：加权和，再 Sigmoid。

输出层假定五个隐藏输出是 `0.80, 0.65, 0.70, 0.20, 0.30`，四个原始分数是 `3.2, 1.1, 0.8, 0.5`。Softmax 之后讲义给的概率是西瓜 78%、苹果 12%、葡萄 7%、香蕉 3%。预测对了，但还不是理想的 one-hot。

损失用交叉熵 `L = -Σ t_k log p_k`。正确答案是西瓜：

```text
L = -log(0.78) = 0.248
```

损失越小，分类越好。Softmax 加交叉熵时，输出误差是 `误差 = 概率 - 目标`：

| 水果 | 概率 | 目标 | 误差 |
| --- | --- | --- | --- |
| Watermelon | 0.78 | 1 | -0.22 |
| Apple | 0.12 | 0 | +0.12 |
| Grapes | 0.07 | 0 | +0.07 |
| Banana | 0.03 | 0 | +0.03 |

反向传播示例：`h1 = 0.80`，它连到西瓜神经元的权重是 `0.60`。

```text
∂L/∂w = 误差 × h = (-0.22)×0.80 = -0.176
学习率 0.1
w_new = 0.60 - 0.1×(-0.176) = 0.6176
```

权重从 0.60 增到 0.6176，因为西瓜的概率还低于目标，这条连接被加强。

讲义给的训练趋势：西瓜概率从 epoch 1 的 0.45，到 10 轮 0.61、50 轮 0.78、100 轮 0.92、500 轮 0.99。损失从 0.80 降到 0.01。

前面的神经元问的是：每个特征该贡献多大，也就是颜色×权重、大小×权重……它用很多权重间接画出决策边界。

RBF 改成直接量相似度。隐藏神经元存一个原型（中心）。例如西瓜中心 `c = [0.3, 1.0, 0.5, 1.0]`，新水果 `x = [0.35, 0.95, 0.40, 0.90]`，算欧氏距离 `d = ||x - c||`。越像，距离越小。

常用激活是高斯。讲义写法是距离越小激活越接近 1：

```text
φ(d) = exp( - d^2 / (2 σ^2) )
σ = 0.5 时：
d = 0.1 → φ ≈ 0.98
d = 2   → φ ≈ 0.0003
```

对照：

| | 普通 ANN 隐藏神经元 | RBF 隐藏神经元 |
| --- | --- | --- |
| 计算 | `a = f(w x + b)` | `a = φ(\|\|x - c\|\|)` |
| 存的参数 | 权重和偏置 | 中心和宽度 σ |
| 问的问题 | 怎样的特征组合像西瓜 | 离典型西瓜有多近 |
| 角色 | 特征检测，全局近似 | 相似度检测，局部近似 |
| 层数 | 可以很多层 | 讲义写明严格只有一个隐藏层 |
| 激活 | Sigmoid、Tanh、ReLU、Leaky ReLU | 最常见是高斯 |
| 训练 | 反向传播 | 选中心，再训练输出权重 |
| 数据 | 大数据集更好 | 小数据集通常更快；维度很高时变差 |
| 解释 | 往往难解释 | 更直观 |

RNN 用环把以前的输入留住，适合随时间变化的任务。前馈网络没有这个记忆。

序列：顺序本身有意义，前后元素互相提供上下文。非序列的例子：一张表格里每一行是一笔支付申请，列是商户类型、地点、身份分、年限；行的先后一般没有时间含义。

课堂讨论把「序列数据有什么特点」收成三条，下载的 PDF 这一页几乎没有字，以投影为准：

1. Order Matters。元素的排列会改变意思。例子是句子里词的顺序。
2. Temporal or Sequential Relationship。元素通常按时间、按固定顺序被观测。例子是股价这种时间序列，不同时刻各有一个值。
3. Variable Length。序列可长可短。句子长度不同；基因组里 DNA 序列的长度也随生物而变。

下一张讨论页说，建模序列往往要用专门的方法。深度学习里常用 RNN、Transformer、LSTM，因为它们能抓住随时间变化的依赖。传统统计里，自回归模型（autoregressive models）也用来做时间序列分析和预测。GRU 是后文才展开的 LSTM 变体，这张列表里没有单独写 GRU。

最早的语言模型靠计数预测下一个词。`I drink a cup of ___`：coffee 5000，tea 3000，water 1000，airplane 0，总数 9000，所以 `P(coffee | cup of) = 5000/9000`，预测 coffee。

N-gram 不看整句历史，只看前面 `N-1` 个词。Bigram 看前 1 个词，Trigram 看前 2 个词。Trigram 上下文更多，通常比 Bigram 准。

三个限制：

1. 数据稀疏。见过 “The intelligent student solved”，没见过 “The brilliant student solved”，就当成完全不同的模式。
2. 窗口固定。Trigram 只记得前两个词。句子 “The fruit that I bought yesterday from the market was an apple.” 里，预测 apple 需要远处的 fruit，Trigram 够不着。
3. 内存。词表 100,000 时，可能的 trigram 是 `100000^3`，存不下。

词表 1000、允许重复时：unigram 1000，bigram `1000^2 = 1,000,000`，trigram `1000^3 = 10^9`，4-gram `1000^4 = 10^12`。一般式是 `V^N`。

因此改用神经网络学习 `P(word | context)`，用稠密向量表示词，而不是把每一种组合都存成一张表。

### 4. RNN 的计算（第 46–50 页）

![第4章第46页](slides/ch04/p046.jpg)

四个量：

1. 当前输入 `x_t`：这个时刻的词或今天的价格。
2. 上一隐藏状态 `h_{t-1}`：带到现在的记忆。
3. 新隐藏状态 `h_t`：由 `x_t` 和 `h_{t-1}` 合成。
4. 当前输出 `y_t`：从新隐藏状态算出。

```text
h_t = f(W_xh x_t + W_hh h_{t-1} + b_h)
y_t = g(W_hy h_t + b_y)
```

`f` 的例子是 tanh。隐藏状态是一个固定长度的向量，例如讲义写的 `[0.18, -0.42, 0.04, 0.60, …, -0.3]`。它压缩到目前为止的历史；每一步用当前输入和上一步隐藏状态更新；同一套权重用在所有时间步，所以序列多长都能用同一组参数。

RNN 在时间上展开后再反向传播，叫 Backpropagation Through Time。10 个时间步可以想成横着的 10 层，但这 10 层共用 `W_xh`、`W_hh`、`W_hy`。

应用：语言建模和翻译，语音，股价和天气。

实际上隐藏状态长度固定，开头那个 token 的特征在更新中会变淡。讲义的数字例子：movie 的特征从 `h1 = 1.0` 到 `h2 = 0.5`，到 `h10 = 0.06`。再加上梯度消失或爆炸，长期依赖学不动。一步一步算，也不能像普通层那样并行，错了要沿整段序列传回去，训练慢。LSTM 和 GRU 是为这些限制做的变体。

梯度消失：tanh 或 sigmoid 的导数是小于 1 的分数，沿时间连乘，误差信号指数变小，早期步骤几乎得不到学习信号。讲义强调这是结构后果，不是调一个学习率就能去掉，要换结构。

梯度爆炸：连乘的数大于 1，更新过大，训练崩。梯度裁剪可以压住，但根子仍是这个结构。

即便梯度还在，普通 RNN 的隐藏状态也不会选择记什么。每来一个新输入就整页重写，像一块没有橡皮选择的便签。

三种接法：

| 接法 | 例子 |
| --- | --- |
| One-to-Many | 一张图生成一句描述 |
| Many-to-One | 一整句得到一个情感标签 |
| Many-to-Many | 翻译，或视频逐帧 |

优点：能吃变长序列；权重共享所以参数少；预测带着历史；可以来一个处理一个，适合流数据。

第 64 页把后面的发展收成一条线，适合当总览而不是当公式：

统计语言模型（数词频，不能泛化）→ N-gram（只看前 N 个词，上下文有限）→ 神经语言模型（用网络学概率，窗口仍固定）→ 词向量 → RNN（有序列记忆，梯度消失）→ LSTM / GRU（长期记忆，但仍要按顺序算）→ 编码器-解码器（翻译框架，有信息瓶颈）→ Attention（盯相关的词，仍常和 RNN 绑在一起）→ Self-Attention → Transformer（并行的注意力，是现代大模型的底子，计算贵）。

细胞状态 `C_t` 是一条长期记忆传送带，沿时间只有轻微的线性改动，梯度可以沿它走很远。隐藏状态 `h_t` 是短期记忆，交给下一步和上一层。

门是学出来的阀门。接近 1 就放行，接近 0 就拦住。数值由当前输入和先前状态算出来，不是人工固定的。RNN 的记忆是结构的副作用；LSTM 和 GRU 把记忆当成要控制的目标。

课堂投影把调节方式收成一问：不要每一步都盲目覆盖状态，先问要不要更新，要的话更新多少。三个门都由 Sigmoid 和逐元素乘法组成。投影上标红的三个词就是考试时要咬住的：遗忘门丢掉旧细胞状态里 irrelevant 的信息；输入门写入来自当前输入和上一隐藏状态的 new information；输出门决定更新后的细胞状态里，哪一部分 portion 变成新的隐藏状态。

三个门都先用 Sigmoid，范围 0 到 1：

| 门 | 问的问题 | 公式 | 作用 |
| --- | --- | --- | --- |
| Forget `f_t` | 该忘掉什么 | `σ(W_f · [h_{t-1}, x_t] + b_f)` | 旧细胞状态 `C_{t-1}` 留多少 |
| Input `i_t` | 该记住什么 | `σ(W_i · [h_{t-1}, x_t] + b_i)` | 新信息写入多少 |
| Candidate `C~_t` | 新记忆长什么样 | `tanh(W_c · [h_{t-1}, x_t] + b_c)` | 候选值，范围约 -1 到 1 |
| Output `o_t` | 该露出什么 | `σ(W_o · [h_{t-1}, x_t] + b_o)` | 细胞状态的哪一部分变成 `h_t` |

细胞状态更新：

```text
C_t = f_t ⊙ C_{t-1} + i_t ⊙ C~_t
h_t = o_t ⊙ tanh(C_t)
```

`⊙` 是逐元素相乘。

讲义例子：

- 遗忘：Peter lives in Vancouver，后来 Peter moved to Toronto。见到 Toronto，Vancouver 过时，遗忘门可以给 Vancouver 0.1，意思是大部分忘掉。
- 输入：The capital of France is Paris。Paris 重要，输入门可以给 0.95，强写入。
- 输出：The cat chased the mouse。预测 chased 后面时，露出 cat、chased 和动物上下文，压住无关信息。
- 三个门一起：She likes to _____ books。忘掉昨天的无关上下文；写入 she、likes、to；likes to 强烈暗示后面是动词。

相对 LSTM 的三处改结构：

1. 把细胞状态和隐藏状态合并成一个 `h_t`。
2. 遗忘门和输入门合成一个更新门 `z_t`。留下多少过去，和写入多少新候选，用 `1 - z_t` 和 `z_t` 互补。
3. 不再单设输出门。重置门 `r_t` 作用在上一隐藏状态上，决定做新候选时看多少过去。

```text
z_t = σ(W_z · [h_{t-1}, x_t] + b_z)
r_t = σ(W_r · [h_{t-1}, x_t] + b_r)
h~_t = tanh(W · [r_t ⊙ h_{t-1}, x_t] + b)
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h~_t
```

第 88–89 页课堂练习要的三点：

1. 参数：LSTM 有 4 套权重（3 个门 + 1 个候选），GRU 有 3 套（2 个门 + 1 个候选），细胞参数大约少 25%。
2. 速度：每步矩阵乘法更少，通常训练更快，较少样本也能收敛，适合小数据或算力紧的场合。
3. 表达力：LSTM 单独的细胞状态是一条更不受阻的线性通路，极复杂、极长的时间依赖上可能更强。

LSTM 对很长的句子仍会吃力，而且必须 `t1 → t2 → t3`，因为这一步的隐藏状态依赖上一步。例子：The student who won the science competition after many months of preparation was given a scholarship。要连上 student 和 was given，中间隔着很多词。

注意力改成：处理 mouse 时可以直接看 cat 和 chased，不必穿过一串隐藏状态。所有词可以同时互相看，这叫 self-attention，距离变成 1 步。课堂上同一页还画了 The monkey ate that banana because it was too hungry，`it` 直接连到句中其他词，没有再给一套新的百分比。

投影把「怎样把按顺序的计算改成并行」收成两件事，页角是 111：

- Attention between tokens：每个词可以直接看其他词。这个想法就是 Attention。
- Position：并行之后模型不再从左到右走，所以每个 token 在句中的位置必须另外编码。

同一页的数据流是：

```text
INPUT WORD → EMBEDDING，再加上 POSITIONAL ENCODING → SELF ATTENTION → CONTEXTUAL EMBEDDING
```

三个好处：可以并行训练；长距离记忆更好，scientist 和 published 中间隔很多词也能直接连；规模上比「把组合都学进 LSTM」更容易做大。

Query、Key、Value，讲义用搜索来比喻：

| | 搜索 | 在句子里 |
| --- | --- | --- |
| Query | 你打进搜索框的话 | 当前 token 在找什么上下文 |
| Key | 每条结果的标题或标签 | 那个 token 宣称自己有什么 |
| Value | 视频本身 | 真正拿来混合的内容 |

公式：

```text
Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
```

三步：`Q` 和 `K` 做点积看有多对齐；除以 `sqrt(d_k)` 再 Softmax，变成和为 1 的权重；用权重对各个 Value 加权求和。

第 100–105 页的完整例子，建议按这六步默写：

句子：The animal didn't cross the street because it was tired. 问 it 指谁。

1. 每个词变成向量。
2. 每个词产生 Query、Key、Value。it 的 Query 问：我最可能指谁。
3. it 的 Query 和每个词的 Key 比。讲义给的分数：The 0.02，animal 0.60，didn't 0.03，cross 0.01，street 0.05，because 0.09，tired 0.20。
4. Softmax 之后：animal 60%，tired 20%，because 9%，street 5%，其余 6%。
5. 输出 = `0.60×Value(animal) + 0.20×Value(tired) + 0.09×Value(because) + …`
6. 之前 it 只是代词；之后 it 变成「那只疲倦的动物」。

多头：每一头是一套独立注意力，像一双专门看某种关系的眼睛。讲义的例子是主语动词一致、代词指代、语义、句子结构。一头一个时刻主要看一种关系，多头就同时看语法、意义、上下文、指代、词序、话题。

RNN、LSTM、Transformer（第 108 页）：

| | RNN | LSTM | Transformer |
| --- | --- | --- | --- |
| 记忆 | 隐藏状态 | 细胞状态 + 门 | 注意力 |
| 长期依赖 | 差 | 较好 | 好 |
| 并行训练 | 不能 | 不能 | 能 |
| 训练速度 | 慢 | 慢 | 快 |
| 很长的文档 | 差 | 中等 | 好 |
| 现代大模型的基础 | 否 | 否 | 是 |

1. Input Embedding：词或 token 变成向量。
2. Positional Encoding：模型不是按顺序读的，所以要另加词序信息。
3. Self-Attention：处理每个词时看句子的其他部分。例子：The cat sat on the mat 里，sat 可能更看 cat 而不是 mat。

Segment embedding（第 111 页，BERT 这一类编码器）：位置编码只告诉下标，不告诉这个 token 属于哪一句。两段文本同时输入时要有句子身份。用途：问答（问题 + 段落），自然语言推断（前提 + 假设），下一句预测。

一个 Transformer block 有两个子层：

- Multi-Head Self-Attention：把输入投影成 Q、K、V，多头并行看不同关系。
- Position-wise Feed-Forward：两层线性变换，中间一个非线性（GELU 或 ReLU）。每个位置用同一套，但各自算。

影响（第 115 页）：自注意力抓住长距离；并行所以训练和推理更快；能做大；文本、图像、音频都能用；预训练模型可以迁到很多任务。

这些是讲义自己的写法，换一套常见教材公式会对不上答案。

- 第 2 章四个点那题的损失是 `(ŷ - y)^2`，梯度里保留系数 2，学习率 0.01。
- Week 2 讨论的单神经元用的是另一套：`L = (1/2)(t - y)^2`，学习率 0.1，`x = 2`，`w = 3`，`t = 4`。两套不要混。手算在 `04-Discussion考点.md`。
- 案例 3 的输出误差是 `概率 - 目标`，不是目标减概率。权重更新是 `w - η × 梯度`。
- 苹果神经元的后续分数用偏置 `-4.5`，得到 `+2.25`。
- RBF 用讲义已经算出的距离，再套 `exp(-d^2 / (2σ^2))`，`σ = 0.5`。
- Softmax 先指数，再除以指数之和。
